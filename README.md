## 🛠️ Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   ```
2. **Install dependencies:**
   ```bash
   npm install
   # or yarn / pnpm install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```
